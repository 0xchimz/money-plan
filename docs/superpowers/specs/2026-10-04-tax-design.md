## 1. เป้าหมายและขอบเขต

ให้แต่ละ user เห็นภาษีเงินได้บุคคลธรรมดาของปีนี้ได้ตลอดปี โดยไม่ต้องคำนวณใหม่เองทุกครั้งที่ตัวเลขเปลี่ยน: ต้องจ่ายเพิ่มหรือได้คืนเท่าไหร่, อยู่ขั้นไหน, เงินสำรองพอไหม, และลดได้อีกเท่าไหร่จากช่องลดหย่อนที่ยังเหลือ

เป็นตัวช่วยประมาณการ ไม่ใช่ที่ยื่นภาษี และไม่ใช่คำแนะนำทางภาษี

**สิ่งที่ Chin ตัดสินใจแล้ว**
- ยอดทั้งปีของบรรทัดที่ผูกงบ = จ่ายแล้วสะสม + ยอดก้อน + งบรายเดือน × เดือนที่เหลือ (ผูกสดกับ Planning)
- เลือกที่แถวงบใน Planning ว่าใช้เป็นเงินได้หรือลดหย่อนชนิดไหน
- แต่ละหมวดเพิ่มบรรทัดกรอกเองได้ (แบบ iTax)
- เงินได้ v1: 40(1), 40(2), 40(5) เท่านั้น
- v1 รวม: เงินสำรองภาษีพอไหม + เทียบฉากทัศน์
- หน้าจอแบบ A (กรอกซ้าย ผลลัพธ์ขวา)

**ถือว่าเสร็จเมื่อ**
- ใส่ตัวเลขปี 2569 ของ Chin แล้วได้: เงินได้สุทธิ 1,461,063.51 · ภาษีทั้งปี 230,265.88 · จ่ายเพิ่ม 21,011.47 · เงินสำรองถึงวันยื่น 22,178.09 (พอ เหลือ 1,166.62) · กลุ่มเกษียณเหลือช่อง 179,525.51 ลดภาษีได้ 44,881.38
- แก้ยอดแถว RMF ใน Planning แล้วเปิดหน้าภาษี ยอดทั้งปีและภาษีเปลี่ยนตามโดยไม่ต้องกรอกอะไรเพิ่ม
- user คนที่ 2 เห็นเฉพาะข้อมูลภาษีของตัวเอง (`test/isolation.test.ts`)
- ใช้ได้ทั้ง desktop และมือถือ (< 1024px) ตามกติกาใน `2026-10-03-mobile-design.md`
- `pnpm typecheck`, `pnpm test`, `pnpm lint`, `pnpm build` ผ่าน

**ไม่อยู่ในงานนี้** (เลื่อนไว้): สรุปสำหรับกรอก ภ.ง.ด.90 · เงินได้ 40(3), 40(4), 40(6)–40(8), เงินได้ต่างประเทศ · ยื่นรวมกับคู่สมรส · หักค่าใช้จ่ายตามจริง · ภาษีครึ่งปี (ภ.ง.ด.94) · ผูกเงินสำรองภาษีกับแถว Balance · แก้กติกาจากหน้าเว็บ · ปีภาษีย้อนหลังก่อน 2569

## 3. กติกา (`shared/tax-rules.ts`)

```ts
interface TaxRules {
  year: number                                   // ค.ศ. เช่น 2026 (แสดงผลเป็น พ.ศ. 2569)
  brackets: { upTo: number | null; rate: number }[]
  kinds: TaxKind[]
  groupCaps: { id: string; label: string; cap: number }[]         // เช่น retire 500,000 · lifeHealth 100,000
  expense: { wage: { rate: number; cap: number }; rent: { rate: number } }
  altTax: { rate: number; minIncome: number; waiveUpTo: number }  // วิธีที่ 2: 0.5%, 120,000, 5,000
  donation: { capPctOfNet: number }                               // 10%
  filingMonth: string                                             // 'YYYY-MM' เดือนที่จ่ายภาษี (ปีถัดไป-03)
}
interface TaxKind {
  key: string                                    // เก็บใน DB: 'inc_wage', 'ded_rmf', 'wht', ...
  section: 'income' | 'family' | 'insurance' | 'fund' | 'home' | 'donation' | 'other' | 'wht' | 'reserve'
  label: string
  budgetTypes: BudgetType[]                      // แถวงบประเภทไหนเลือกชนิดนี้ได้ · [] = กรอกเองในหน้าภาษีเท่านั้น
  cap?: number                                   // เพดานคงที่ต่อปี
  capPctOfIncome?: number                        // เพดานเป็น % ของเงินได้พึงประเมินรวม
  group?: string                                 // อยู่ในเพดานกลุ่มไหน
  multiplier?: number                            // บริจาค 2 เท่า = 2
  auto?: number                                  // ได้เองไม่ต้องกรอก (ลดหย่อนส่วนตัว 60,000)
  advice?: { money: 'kept' | 'spent'; note: string }   // ใช้ในคำแนะนำ · ไม่มี = ไม่แนะนำให้เพิ่ม
}
```

## 4. ตัวคำนวณ (`shared/tax.ts`)

ฟังก์ชันล้วน ไม่แตะ DB หรือเวลา · เงินทุกยอดปัดเป็น 2 ตำแหน่งที่ขั้นสุดท้ายของแต่ละบรรทัด

**4.1 ยอดทั้งปีของบรรทัด** — `annualOf(line, budgetThb, year)`
- บรรทัดกรอกเอง: `paid + lump`
- บรรทัดผูกงบ: `paid + lump + budgetThb × เดือนหลัง asOf จนถึง ธ.ค.` · `asOf` ว่าง = ยังไม่เคยกรอกยอดสะสม → `budgetThb × 12` และขึ้นป้าย "ยังไม่ได้กรอกยอดสะสม"
- `asOf` เป็นของแต่ละบรรทัด: ไม่ได้แก้เดือนไหนก็ยังคิดจากเดือนเดิมถูกต้อง · ค้างเกิน 2 เดือนจากเดือนปัจจุบัน (เวลา Bangkok) ขึ้นป้ายเตือน

**4.2 ภาษี** — `computeTax(rules, amounts)` โดย `amounts` = ยอดทั้งปีต่อบรรทัดพร้อมชนิด · คืนทุกขั้นเพื่อแสดงผล
1. เงินได้พึงประเมินรวม แยกตามชนิด
2. หักค่าใช้จ่าย: 40(1) + 40(2) รวมกัน 50% ไม่เกิน 100,000 · 40(5) เหมา 30%
3. ลดหย่อนทุกชนิดยกเว้นบริจาค: ตัดตามเพดานของชนิด (คงที่ / % ของเงินได้ข้อ 1) แล้วตัดตามเพดานกลุ่ม · คืนทั้งยอดที่กรอกและยอดที่นับได้ต่อชนิด
4. บริจาค (คิดท้ายสุด): ยอด × ตัวคูณ รวมไม่เกิน 10% ของ (ข้อ 1 − ข้อ 2 − ข้อ 3)
5. เงินได้สุทธิ = ข้อ 1 − 2 − 3 − 4 (ไม่ต่ำกว่า 0) → ภาษีขั้นบันได พร้อมยอดภาษีแต่ละขั้นและขั้นที่อยู่
6. วิธีที่ 2: เงินได้ที่ไม่ใช่ 40(1) ≥ 120,000 → 0.5% ของยอดนั้น · ถ้าได้ไม่เกิน 5,000 ไม่ใช้ · ภาษีทั้งปี = ค่าที่มากกว่าระหว่างข้อ 5 กับข้อ 6
7. จ่ายเพิ่ม (+) หรือได้คืน (−) = ภาษีทั้งปี − หัก ณ ที่จ่าย

**4.3 คำแนะนำ** — `advise(rules, amounts)` ไม่ใช้สูตรลัด: สำหรับแต่ละชนิดที่มี `advice`
- ช่องที่เหลือ = ยอดสูงสุดที่เพิ่มได้ก่อนชนเพดานชนิด / กลุ่ม / บริจาค (ชนิดในกลุ่มเดียวกันรวมเป็นคำแนะนำเดียว เช่น "RMF / PVD")
- ภาษีที่ลดได้ = `computeTax` ปัจจุบัน − `computeTax` เมื่อเพิ่มยอดเต็มช่อง (ถูกต้องแม้ข้ามขั้นภาษีหรือเพดานซ้อนกัน)
- แสดง: ช่องที่เหลือ, ภาษีที่ลดได้, เฉลี่ยต่อเดือนที่เหลือของปี, และ `advice.note` (เงินยังเป็นของเรา + เงื่อนไขล็อก / เงินออกจากกระเป๋า)
- เรียงตามภาษีที่ลดได้ มากไปน้อย · ชนิดที่ยังไม่มีบรรทัดเลยแต่ใช้ได้ (เช่น ประกันสุขภาพบิดามารดา) รวมอยู่ด้วย · ไม่แสดงชนิดที่ช่องเหลือ 0

**4.4 ฉากทัศน์** — `applyScenario(amounts, changes)` = เพิ่ม `changes` (ชนิด + ยอดบวกหรือลบ) เป็นบรรทัดเสริม แล้วใช้ `computeTax` ตัวเดียวกัน · ยอดรวมของชนิดหลังปรับไม่ต่ำกว่า 0 · ส่วนที่เกินเพดานไม่ถูกนับและขึ้นป้ายเตือน
ตารางเทียบแสดงต่อฉากทัศน์: เงินได้สุทธิ, ขั้น, ภาษีทั้งปี, จ่ายเพิ่ม/ได้คืน, ภาษีลดลงเทียบตัวเลขจริง, เงินที่ต้องใช้ (ผลรวมยอดที่เพิ่มของชนิดลดหย่อน), เงินยังเป็นของเรา (ชนิดที่ `advice.money = 'kept'`), ผลสุทธิ = ภาษีลดลง − เงินที่ออกจากกระเป๋าจริง (ใน mockup เขียนว่า "ต้นทุนสุทธิ" → ใช้คำว่า "ผลสุทธิ" เพราะค่าบวกคือได้ประโยชน์)

**4.5 เงินสำรองภาษี** — `reserveStatus(...)`: มีถึงวันยื่น = ยอดที่กรอก + ผลรวมแถวงบชนิดเงินสำรอง × เดือนหลัง `reserveAsOf` จนถึง `filingMonth` · เทียบกับยอดจ่ายเพิ่ม → พอ (เหลือเท่าไหร่) หรือขาด (เท่าไหร่ + ต้องกันเพิ่มต่อเดือน) · ถ้าได้คืนภาษี การ์ดแสดงแค่ยอดที่มี

## 5. ข้อมูล (`migrations/0004_tax.sql`)

```sql
ALTER TABLE budget_lines ADD COLUMN tax_kind TEXT;   -- NULL = ไม่ใช้กับภาษี · key ของ TaxKind
CREATE UNIQUE INDEX budget_lines_user_id ON budget_lines(user_id, id);   -- ให้ composite FK ชี้มาได้

CREATE TABLE tax_years (
  user_id        INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  year           INTEGER NOT NULL,           -- ค.ศ.
  reserve_thb    REAL NOT NULL DEFAULT 0,    -- เงินสำรองภาษีที่มีอยู่
  reserve_expr   TEXT,
  reserve_as_of  TEXT,                       -- YYYY-MM
  PRIMARY KEY (user_id, year)
);

CREATE TABLE tax_lines (
  id              INTEGER PRIMARY KEY,
  user_id         INTEGER NOT NULL,
  year            INTEGER NOT NULL,
  kind            TEXT NOT NULL,
  label           TEXT NOT NULL,
  budget_line_id  INTEGER,                   -- NULL = กรอกเอง
  paid_thb        REAL NOT NULL DEFAULT 0,   -- กรอกเอง: ยอดทั้งปี · ผูกงบ: จ่ายแล้วสะสม
  paid_expr       TEXT,
  as_of           TEXT,                      -- YYYY-MM · ใช้เฉพาะบรรทัดผูกงบ
  lump_thb        REAL NOT NULL DEFAULT 0,   -- ยอดก้อนที่จะมีเพิ่ม · ใช้เฉพาะบรรทัดผูกงบ
  lump_expr       TEXT,
  sort            INTEGER NOT NULL DEFAULT 0,
  FOREIGN KEY (user_id, year) REFERENCES tax_years(user_id, year) ON DELETE CASCADE,
  FOREIGN KEY (user_id, budget_line_id) REFERENCES budget_lines(user_id, id) ON DELETE CASCADE,
  UNIQUE (user_id, year, budget_line_id)
);

CREATE TABLE tax_scenarios (
  id       INTEGER PRIMARY KEY,
  user_id  INTEGER NOT NULL,
  year     INTEGER NOT NULL,
  name     TEXT NOT NULL,
  changes  TEXT NOT NULL,                    -- JSON: [{ "kind": "ded_rmf", "thb": 100000 }]
  sort     INTEGER NOT NULL DEFAULT 0,
  FOREIGN KEY (user_id, year) REFERENCES tax_years(user_id, year) ON DELETE CASCADE
);
```

**ความสัมพันธ์กับแถวงบ**
- ใช้เฉพาะงบชุด `main` · ช่องเลือกภาษีแสดงเฉพาะตอนดูชุด `main` · `copyScenario` ไม่คัดลอก `tax_kind`
- แถวงบที่มี `tax_kind` ขึ้นในหน้าภาษีทันทีแม้ยังไม่มีแถวใน `tax_lines` (ยอด = งบ × 12) · `tax_lines` ถูกสร้างเมื่อกรอกยอดสะสมหรือยอดก้อนครั้งแรก
- ชนิดและชื่อของบรรทัดผูกงบตามแถวงบเสมอ (`tax_kind`, `item`)
- ลบแถวงบ หรือเอาป้ายภาษีออก: ถ้าบรรทัดภาษีมียอดสะสมหรือยอดก้อน > 0 → worker ปลดการผูกก่อน (`budget_line_id = NULL`, `paid_thb = paid + lump`) บรรทัดกลายเป็นกรอกเองและยอดที่จ่ายไปแล้วไม่หาย · ถ้ายอดเป็น 0 → ลบ · FK `ON DELETE CASCADE` เป็นตัวกันพลาดเท่านั้น
- เปลี่ยนป้ายเป็นชนิดอื่น: บรรทัดย้ายหมวดตาม ยอดสะสมอยู่ครบ
- `tax_kind` ต้องเป็น key ที่ใช้กับประเภทแถวนั้นได้ (`budgetTypes`) ไม่งั้น 400

## 6. API (`worker/tax.ts` + route ใน `worker/index.ts`)

ทุก route คืน `Tax` ทั้งก้อนหลังเขียน (แบบเดียวกับ Planning) · ทุก query มี `user_id`

```ts
interface Tax {
  year: number
  years: number[]                    // ปีที่มีกติกา
  lines: TaxLine[]                   // รวมบรรทัดผูกงบที่ยังไม่มีแถวใน tax_lines (id = null)
  reserve: { thb: number; expr: string | null; asOf: string | null }
  scenarios: { id: number; name: string; changes: { kind: string; thb: number }[] }[]
  today: string                      // YYYY-MM เวลา Bangkok ใช้ตั้งค่าเริ่มต้นของ asOf และป้ายเตือน
}
interface TaxLine {
  id: number | null
  kind: string
  label: string
  budget: { lineId: number; thb: number } | null
  paid: number; paidExpr: string | null
  asOf: string | null
  lump: number; lumpExpr: string | null
}
```

| Method | Path | ทำอะไร |
| --- | --- | --- |
| GET | `/api/tax?year=` | อ่าน · ไม่ระบุปี = ปีปัจจุบัน (Bangkok) · สร้าง `tax_years` เมื่อเขียนครั้งแรก ไม่ใช่ตอนอ่าน |
| POST | `/api/tax/:year/lines` | เพิ่มบรรทัดกรอกเอง `{ kind, label, thb, expr }` |
| PATCH | `/api/tax/lines/:id` | แก้บรรทัดกรอกเอง (label, ยอด) หรือบรรทัดผูกงบ (paid, asOf, lump) |
| PUT | `/api/tax/:year/budget-lines/:lineId` | กรอกยอดสะสม/ยอดก้อนของบรรทัดผูกงบครั้งแรก (upsert) |
| DELETE | `/api/tax/lines/:id` | ลบบรรทัดกรอกเอง · บรรทัดผูกงบลบไม่ได้ (409 บอกให้เอาป้ายออกที่ Planning) |
| PUT | `/api/tax/:year/reserve` | `{ thb, expr, asOf }` |
| POST / PATCH / DELETE | `/api/tax/:year/scenarios`, `/api/tax/scenarios/:id` | ฉากทัศน์ |
| POST | `/api/tax/scenarios/:id/apply` | "ใช้เป็นตัวเลขจริง": แต่ละรายการที่เปลี่ยนกลายเป็นบรรทัดกรอกเอง แล้วลบฉากทัศน์ · มีรายการติดลบ → 409 (ให้ไปลดยอดที่บรรทัดจริงเอง) |
| PATCH | `/api/planning/lines/:id` (เดิม) | รับ `taxKind` เพิ่ม · `BudgetLineRow` มี `taxKind: string \| null` |

ตรวจ input: ยอด ≥ 0 และเป็นตัวเลข (ฉากทัศน์ติดลบได้), `kind` ต้องมีในกติกาของปีนั้น, `asOf` ต้องเป็นเดือนในปีภาษีนั้น, `reserve.asOf` อยู่ระหว่าง ม.ค. ของปีภาษีถึง `filingMonth`, ปีต้องมีกติกา (ไม่มี = 404), `changes` ไม่เกิน 20 รายการ

## 7. หน้าจอ

**เมนู**: เพิ่ม "ภาษี" เป็นรายการที่ 4 ทั้งแถบบน desktop และแถบล่างมือถือ · route `/tax`

**7.1 Planning** (mockup 1 ท้ายหน้า) — แถวงบของชุด `main` มีตัวเลือก "ภาษี: …" ท้ายแถว (desktop) หรือในแผ่นแก้แถว (มือถือ) · ตัวเลือกกรองตามประเภทแถว: Income → ชนิดเงินได้ · Saving / Expense → ชนิดลดหย่อน, หัก ณ ที่จ่าย, เงินสำรองภาษี · ค่าเริ่มต้น "ไม่ใช้" แสดงจางๆ

**7.2 หน้าภาษี desktop** (mockup 1 แบบ A + mockup 2 ข้อ 1, 4)
- หัว: "ปีภาษี 2569" + ปุ่มสลับ ตัวเลขจริง / ฉากทัศน์
- ซ้าย: การ์ดต่อหมวดตามลำดับในตาราง §3 (ยกเว้นเงินสำรอง) · หัวการ์ด = ชื่อหมวด + ยอดรวมที่นับได้ · แถว = ชื่อ + ป้าย "งบ" ถ้าผูก + บรรทัดรองบอกที่มาของยอด + ป้ายเพดาน ("เต็มเพดาน", "เกินเพดาน นับได้ X") · กดแถว → แผงแก้ในการ์ด · ท้ายการ์ด "+ เพิ่มรายการ" → เลือกชนิดในหมวดนั้น + ชื่อ + ยอดทั้งปี (พิมพ์สูตรได้ ใช้ `MoneyInput` เดิม)
- ขวา (sticky): การ์ดผลลัพธ์ (จ่ายเพิ่ม/ได้คืน, แถบขั้นบันได, เงินได้สุทธิ + ขั้น, ภาษีทั้งปี, หัก ณ ที่จ่าย) · การ์ดเงินสำรองภาษี · การ์ด "ลดภาษีได้อีก" แต่ละข้อมีลิงก์ "ลองในฉากทัศน์"
- ยังไม่มีข้อมูลเลย: การ์ดอธิบาย 2 ทางเริ่ม — ไปติดป้ายที่ Planning หรือเพิ่มเงินได้เอง

**7.3 ฉากทัศน์** (mockup 2 ข้อ 2) — ตารางเทียบ: คอลัมน์แรก = ตัวเลขจริง ตามด้วยฉากทัศน์ทุกชุด · กดคอลัมน์เพื่อแก้ในการ์ดขวา (ชื่อ + รายการที่เปลี่ยน) · ปุ่ม "ใช้ฉากทัศน์นี้เป็นตัวเลขจริง" และ "ลบ" · มือถือ: ตารางปัดแนวนอนได้ (ใช้ `scroll-x.tsx`)

**7.4 มือถือ** (mockup 2 ข้อ 3) — การ์ดหมวดเรียงคอลัมน์เดียว · แถบผลลัพธ์สีเข้มติดเหนือแถบเมนูล่าง (จ่ายเพิ่ม + ขั้น + ลดได้อีก) → แตะเปิดแผ่นผลลัพธ์ที่มีเงินสำรองและคำแนะนำ · แตะแถว → แผ่นแก้ยอด (`Sheet` + `AmountField` เดิม) · จุดแตะ ≥ 44px, ช่องพิมพ์ ≥ 16px

**ข้อความ**: ภาษาไทย · ยอดเงินเต็ม 2 ตำแหน่งมีคอมมา · ปีแสดงเป็น พ.ศ. · ท้ายหน้ามีบรรทัด "ประมาณการจากข้อมูลที่กรอก ตรวจกับกรมสรรพากรก่อนยื่นจริง"

## 8. ข้อผิดพลาดและกรณีขอบ

- เงินได้เป็น 0: ภาษี 0, ไม่มีคำแนะนำ, ไม่หารด้วย 0
- ลดหย่อนเกินเพดาน: นับเท่าเพดาน แสดงทั้งยอดที่กรอกและยอดที่นับได้ ไม่ปฏิเสธการกรอก
- ลดหย่อนรวมมากกว่าเงินได้: เงินได้สุทธิ 0
- หัก ณ ที่จ่ายมากกว่าภาษี: แสดง "ได้คืน" สีเขียว
- บรรทัดผูกงบที่ `asOf` = ธ.ค.: ไม่บวกงบเพิ่ม
- ปีที่ไม่มีกติกา: 404 · หน้าเว็บให้เลือกเฉพาะปีใน `years`
- โหลดหรือบันทึกไม่ได้: ใช้ `PageState` และ toast แบบหน้าอื่น
